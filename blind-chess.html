Connect Google Sign-In

Accounts need a Supabase project and a hosted address — Google will not redirect back to a file on disk. Five steps:

  1. Create a free project at supabase.com.
  2. Open the SQL editor and run supabase-setup.sql, then supabase-social.sql (both next to this file).
  3. Authentication → Providers → enable Google, using a Google Cloud OAuth client.
  4. Paste your project URL and publishable key into SUPABASE_URL and SUPABASE_ANON_KEY near the top of this file's script.
  5. Host it (a Render Static Site works) and add that https address to Supabase's redirect allow-list.
